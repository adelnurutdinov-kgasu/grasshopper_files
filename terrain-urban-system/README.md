# Рельеф и городская среда

[← К списку проектов](../README.md#terrain-urban-system)

<p><img src="demo/relief_demo_v4_preview.gif" width="80%" alt="Демонстрация"></p>

Описание задачи и результат — [на главной странице](../README.md#terrain-urban-system).

Демонстрационный участок 300 × 300 м. Из мэша восстанавливается поверхность, затем идёт горизонтальная нарезка с шагом 2 м; четыре цветные оси задают дороги (красный, оранжевый, жёлтый, зелёный), голубая граница имеет нулевую ширину. Строятся дорожная сеть и кварталы, озеленение, посадки условных деревьев и тестовые объёмы. Меняются трасса, ширина дороги и зелёные полосы.

Данные тестовые (синтетический участок), не реальный генплан. Это не раскладка для лазерной резки и не инженерный проект.

## Что в папке

| Путь | Содержимое |

| `docs/edits_v4.md`, `run_v3_legacy.md` | заметки предыдущих сессий; запуск описан для V3 |

## Запуск

1. Открыть `inputs/relief_demo_v4_inputs.3dm` в Rhino 8, затем `definition/relief_demo_v4.gh`.
2. Считыватели цветов смотрят на активный документ Rhino; после правки линий пересчитать схему. Посторонние объекты тех же цветов попадают в выборку.
3. Отрисовка: `python scripts/render_demo_v4.py`; нужны numpy, Pillow, imageio_ffmpeg. Скрипт добавляет в путь папку `python_packages` (в пакет не входит) и использует шрифты Windows (Arial, Consolas).

## Не подтверждено

- Живая смена цвета линии и добавление новых линий с изменением класса дороги в этом пакете не проверялись; ролик этот сценарий явно не показывает.
- Отложенные правки: упорядочить канвас GH, переписать подписи ролика. Пакет собран до них.
- Слоистая подложка в GH — сохранённый мэш текущего участка; при замене рельефа обновить.
- Часть старых веток GH отключена из-за отсутствующих входов исторического генплана.
