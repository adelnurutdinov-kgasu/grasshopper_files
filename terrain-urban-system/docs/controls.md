# Управление схемой

## Цвета осей

Дороги задаются линиями в Rhino; класс дороги определяется цветом линии.

| Цвет | RGB |
|---|---|
| красный | 255, 0, 0 |
| оранжевый | 255, 127, 0 |
| жёлтый | 255, 255, 0 |
| зелёный | 0, 255, 0 |
| голубой (граница участка, ширина 0) | 0, 255, 255 |

Считыватели цвета берут объекты этих цветов из активного документа Rhino, в том числе посторонние; после изменения линий схему нужно пересчитать.

## Ширины

- Панель ширин `d4882244-379f-4ace-b61f-fc148c643f77`: первые четыре значения (8, 7, 14, 10 м) относятся к четырём цветам. Третье значение — жёлтая главная дорога; в ролике оно меняется с 14 до 24 м.
- Полуширина зелёных полос: три ползунка «ШИРИНА ПОПОЛАМ», базовое значение 1,6 м; в ролике доходит до 2,6 м (полная ширина 3,2 → 5,2 м).
- Отступ оси посадки от края дороги: 6 м. Зелёные кластеры получают половину ширины дороги плюс этот отступ; смещения полигонов используют тот же принцип.
- Пешеходная основа проходит под проезжей частью и зеленью; её полуширина больше полуширины дороги на 10 м с каждой стороны. У границы участка с нулевой шириной отступ нулевой, поэтому по периметру рамки нет; край основы обрезается по участку.

## Слои и сечения

Горизонтальные сечения строятся с шагом 2 м. Слоистая подложка в ролике берётся из сохранённого мэша текущего участка; дороги, пешеходное покрытие, озеленение и объекты считаются по гладкой поверхности.

## Состав схемы

- Три кластера озеленения, кластер точек посадки, кластер размещения зданий по высоте, ядро дорог — из более раннего большого файла.
- Три условных дерева встроены в схему; внешние прокси не нужны.
- В файле сохранены отключённые ветки исходного большого файла: они привязаны к объектам генплана, которых в демонстрации нет.
