# Последние правки V4

- Нарезка стала вдвое чаще: шаг 2 м. Слоистая подложка сохраняется на всех этапах после её появления, до финала ролика.
- Восстановлена исходная ветка покрытия `Custom offset #493 → #549 → кластер #556`. Широкая пешеходная основа показана светло-серой под проезжей частью и озеленением; её ширина следует за автомобильной дорогой с добавлением по 10 м с каждой стороны только у настоящих дорог. У служебной границы с нулевой шириной отступ остаётся нулевым — пешеходная рамка по периметру не создаётся. Край покрытия обрезан по демонстрационному участку.
- Пешеходная основа расположена ниже автомобильного покрытия и зелёных полос. В визуальном предпросмотре используются небольшие смещения поверхностей, чтобы избежать наложения цветов.
- Отдельная логика белой осевой разметки при проверке исходного графа не обнаружена. Белый материал в сохранённой схеме относится к зданиям. Новая разметка не добавлялась.
