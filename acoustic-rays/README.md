# Акустические лучи

> Черновик. Формулировка задачи и роль автора: **уточнить**.

Схема Grasshopper для зала: отражатели, лучи и веера лучей до рядов. Отдельная анимация наклона экрана О3 от −16° до +10° показывает нарушение нормы.

## Что в папке

| Путь | Содержимое | Статус |
|---|---|---|
| `demo/rays_sheet.png`, `.svg` | итоговый лист (в SVG текст остаётся текстом) | готово |
| `demo/rays_assembly.mp4`, `.webm`, `.webp` | появление отражателей, 7 с | готово |

| `scripts/` | `render.py`, `anim.py`, `anim2.py`, `sim2.py`, `make.py` + `base.json`, `layout.json` | см. ограничения |
| `definition/` | основная схема GH | **не собрана** |
| `inputs/` | два файла 3DM | **не собраны** |

Данные лежат рядом со скриптами в `scripts/`: скрипты читают их относительно своей папки.

## Важно про расчёт

Анимация наклона считается не в Grasshopper, а скриптом `sim2.py` по геометрии, выгруженной из GH. При 0° результат совпадает с GH (16 рядов). Показатели листа и анимации наклона имеют разные условия и не объединяются.

## Ограничения (из рабочих заметок)

- Основная схема по заметкам — `физика тест11.gh`; рядом есть более поздний `физика тест11_блоки.gh`. Различия не сопоставлены.
- Для схемы нужны два файла 3DM (зал и `физика лучи.3dm`, Import с сохранением ID объектов).
- Считаются 223 компонента из 231; одна ошибка (Loft), 7 предупреждений; параметр Geometry без источника.
- Компонент экспорта JSON в сохранённый GH не попал.
- `render.py` использует шрифты IBM Plex по пути `/root/fonts`; нужны matplotlib, numpy, ffmpeg (libx264, libvpx-vp9, libwebp).
- Пересборка `python make.py` пишет файлы в `out/` с исходными русскими именами; в `demo/` они переименованы.
- На итоговом листе указан Anemone: версия и зависимости не проверены.
