## Состав папки

| Путь | Содержимое |
|---|---|
| `definition/physics_test11_blocks.gh` | схема Grasshopper |
| `inputs/acoustics_base.3dm` | модель зала |
| `inputs/acoustics_rays.3dm` | геометрия для схемы: импортируется в модель зала |
| `demo/rays_sheet.png`, `.svg` | итоговый лист (в SVG текст остаётся текстом) |
| `demo/rays_assembly.*` | отражатели появляются по одному, 7 с (MP4, WebM, WebP, GIF) |
| `demo/screen_tilt.*` | наклон экрана О3 от −16° до +10°, 8 с (MP4, WebM, WebP, GIF) |
| `demo/screen_m16.*`, `screen_0.*`, `screen_p10.*` | стоп-кадры наклона (PNG и SVG) |
| `scripts/` | скрипты отрисовки и расчёта наклона вместе с данными `base.json` и `layout.json` |

## Как открыть схему

Открыть `inputs/acoustics_base.3dm`, сделать Import файла `inputs/acoustics_rays.3dm` (ID объектов при импорте сохраняются, ссылки схемы находят свои точки) и открыть схему. Нужны Rhino 8, Grasshopper и плагин Anemone.

## Скрипты

Скрипты читают данные относительно своей папки, поэтому `base.json` и `layout.json` лежат рядом с ними.

| Файл | Что делает |
|---|---|
| `base.json` | геометрия, выгруженная из Grasshopper: разрез, лучи, веера, ряды, план |
| `layout.json` | позиции блоков на листе, цвета отражателей, диапазон наклона, частота кадров |
| `render.py`, `anim.py` | лист и кадры «сборки» |
| `sim2.py` | расчёт отражений при изменении экрана (мнимый источник, перекрытия балконом и потолком) |
| `anim2.py` | лист и кадры «наклона» |
| `make.py` | собирает всё в папку `out/` (имена файлов там русские, в `demo/` они переименованы) |

Пересборка: `python make.py` или по частям `python make.py stills`, `sborka`, `naklon`. Нужны Python, matplotlib, numpy, ffmpeg (libx264, libvpx-vp9, libwebp) и шрифты IBM Plex Mono и Sans. Путь к шрифтам в `render.py` (`/root/fonts`) заменить на свой.

`base.json` выгружен из схемы отдельным компонентом экспорта; в сохранённый файл схемы он не входит.

## Ограничения модели

- Анимация наклона экрана считается не в Grasshopper, а в `sim2.py` по выгруженной геометрии. При наклоне 0° результат совпадает со схемой (16 рядов, 46 мс). Показатели итогового листа и анимации наклона получены в разных условиях и не сравниваются.
- Нормаль экрана О3 берётся из лучей схемы, а не из формы панели: она отличается от биссектрисы «падающий/отражённый луч» на 5–12°.
- Диапазон наклона ограничен −16°…+10°: при большем наклоне экран выходит за потолок.
- Ряд назначается лучу по ближайшей точке: 17 лучей приходится на 16 рядов, отклонение до 1 м.
