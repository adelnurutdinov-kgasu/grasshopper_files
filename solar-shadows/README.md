## Состав папки

| Путь | Содержимое |
|---|---|
| `definition/physics74_blocks.gh` | схема Grasshopper (последняя версия) |
| `inputs/data.csv` | таблица: 10 городов (широта, восход и закат, азимуты и высоты Солнца по часам, разворот) и 10 схем (размеры, высоты зданий, окна) |
| `inputs/variants/NNN.dwg` | DWG 19 вариантов, показанных в роликах |
| `results/outputs_NNN.txt` | готовые тексты выводов для тех же вариантов |
| `scripts/calc_outputs.py` | независимый расчёт выводов на Python (только стандартная библиотека) |
| `scripts/export_frames.cs` | экспорт кадров из Grasshopper (C# Script) |
| `demo/sheet_variant_128.png` | итоговый лист, Москва, схема 8 |
| `demo/city_sweep.*`, `demo/scheme_sweep.*` | ролики (MP4) и GIF-превью |
| `demo/frames/` | кадры `Y_1C8` (перебор городов) и `Z_12S` (перебор схем в Москве) |

Код варианта `1CS`: `C` — номер города (0 Новороссийск, 1 Ярославль, 2 Москва, 3 Нижний Новгород, 4 Ижевск, 5 Ульяновск, 6 Самара, 7 Саратов, 8 Волгоград, 9 Элиста), `S` — номер схемы. В репозитории 19 вариантов: `108`–`198` с шагом 10 (все города, схема 8) и `120`–`129` (Москва, все схемы).

## Пересчёт выводов

Из папки кейса:

```
python scripts/calc_outputs.py inputs/data.csv 128
```

Можно передать несколько кодов. Вывод совпадает с `results/outputs_128.txt`.

## Что проверено

| Проверка | Результат |
|---|---|
| `calc_outputs.py` по `data.csv` против `results/outputs_NNN.txt` | совпадает для всех 19 вариантов (29.09.2026) |
| Запуск схемы Grasshopper из этой структуры | не выполнялся |
| Какие именно файлы схема читает как входы | не проверялось; `data.csv` и DWG вариантов — файлы, лежавшие рядом с рабочей схемой |
| Ссылки на нормы на листе | не сверялись с действующей редакцией СанПиН |

## Ограничения

- `export_frames.cs` содержит локальный путь папки кадров; перед запуском заменить.
- Геометрия для повторной отрисовки кадров в репозиторий не включена.
- Лицензия не назначена.
