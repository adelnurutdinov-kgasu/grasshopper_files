# Устройство схемы

Схема `definition/theatre_hall_blocks.gh` строит зал, рассадку и рёбра потолка; компоненты разложены по группам с подписями. Перфорация вынесена в отдельную схему `theatre_perforation_spots.gh`.

## Группы схемы зала

| Группа | Что в ней |
|---|---|
| 1 · Рёбра потолка | две опорные дуги → Tween ×5 (+1) → проекция на SubD потолка, 6 ползунков |
| 2 · Стены, пол, проходы | кривые Rhino → Join → Offset → Boundary → Extrude |
| 3 · Рассадка: партер | кластер: ряд минус 0,5 м с концов, место 0,56 м |
| 4 · Рассадка: балкон | тот же кластер |
| 5 · Кресло-эталон | сетка, зеркало |
| 6 · Объёмы в зале | балкон, галереи, порталы (Sweep и Extrude по кривым Rhino) |
| 7 · Над потолком и кровля | |
| 8 · Вне зала | навес и фойе |

## Что от чего зависит

| Система | Вход из Rhino | Цепочка Grasshopper |
|---|---|---|
| Стены и пол | 8 отрезков контура зала | Join → Offset → Boundary → Extrude (высота 8 и 12 м); пол — Boundary |
| Рассадка | 10 параметров с осями рядов (кластеры «партер» и «балкон») | обрезка 0,5 м с концов → n = floor((L − 1,0) / b), b = 0,56 м → Divide Curve + Perp Frames → Orient кресла → Move (0, −20, 0,19) |
| Рёбра потолка | 2 опорные дуги + поверхность SubD | 5 × Tween Through (5 ползунков 0…1) + Tween Consecutive (ползунок 0…2) → Project на SubD → Move +10 |

Исходно партер даёт 683 места (60 рядов), балкон — 226 (20 рядов), всего 909.

Пример расчёта: ряд L = 8,79 м → (8,79 − 1,0) / 0,56 = 13,9 → 13 мест.

## Ползунки рёбер

| Ползунок | Значение | Что делает |
|---|---|---|
| пять ползунков 0…1 | 0 / 0,183 / 0,404 / 0,684 / 1 | положение пяти рёбер между опорными дугами |
| ползунок 0…2 | 1,344 | шестое ребро; при значении больше ≈ 1,35 проекция рвётся на два куска (ребро выходит за SubD) |

## Перфорация потолка

В первом варианте отверстия задавались случайными точками (Populate). В схеме `theatre_perforation_spots.gh` они собраны в локальные регулярные пятна у кромок рёбер.

1. Вход: 6 рёбер потолка (внутренние данные, скопированные из схемы зала) → «Полосы из рёбер» (Loft соседних рёбер) → ползунок «полоса №» (0–4).
2. «Сетка + центры пятен»: регулярная сетка (шаг, м) по изолиниям поверхности; центры пятен вдоль полосы попеременно у кромок.
3. «Расстояние до центра пятна (вытянутость)»: расстояние по поверхности в метрах, вдоль полосы делится на k.
4. Remap с доменом [0, радиус пятна] → Clipped → Graph Mapper → диаметр отверстия; малые отверстия отсеиваются; большие фонари не вырезаются.

| Ползунок | Значение |
|---|---|
| сетка · шаг | 0,25 м |
| пятна · число | 6 |
| пятна · у кромки | 0,15 |
| пятно · радиус | 3 м |
| пятно · вытянутость | 1,8 |
| отверстия · макс. радиус | 0,12 |
| отверстия · мин. радиус | 0,02 |

Итог: 5 полос, 7240 отверстий Ø 40–240 мм (по полосам: 1319, 1350, 1463, 1516, 1592). Surface Split на одну полосу занимает 30–50 с; всё дерево из пяти полос сразу Rhino не считает. Результат по каждой полосе лежит в `scripts/perf/perf_<n>.json` (центр отверстия, нормаль, радиус).

## Как получены состояния для демонстрации

Состояния (масштаб кривых по ширине, ширина места, значения ползунков) перечислены в `scripts/theatre_states.json`. Скрипт `rhino/probe_driver.py` в компоненте Python 3 Script внутри Grasshopper применяет их по очереди, после каждого пересчёта записывает геометрию (стены, пол, рёбра, потолок, кресла) в `scripts/states/theatre_st_<tag>.json`. Листы, кадры и слои рисует `scripts/` по этим файлам, без Rhino.
